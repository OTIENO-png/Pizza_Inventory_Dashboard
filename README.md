# Pizza Inventory Dashboard

This dashboard provides a visual analysis of pizza inventory categorized by size. The charts display the number of pizzas available, their total sales value, and pricing distribution per size.

## 📊 Charts Breakdown

1. **Number of Pizzas by Size**
   - Displays the count of pizzas available for each size (S, M, L, XL, XXL).
   - Shows that sizes L, M, and S dominate the inventory.

2. **Total Value by Size**
   - Represents the total monetary value of pizzas per size.
   - Indicates that large pizzas contribute the most to total value despite similar counts with M and S.

3. **Combined Horizontal Analysis**
   - A summary view showing count, value, and price comparisons across sizes.
   - Useful for identifying inventory and sales concentration at a glance.

## 💡 Key Insights
- **Top Selling Size by Value**: Large (L) pizzas.
- **Most Stocked Size**: Small (S) pizzas.
- **Least Stocked Sizes**: XL and XXL (only 1 each).
